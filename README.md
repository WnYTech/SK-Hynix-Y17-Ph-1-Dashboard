# Y17 Log Workspace

SK hynix Y17 Ph-1의 생산 시스템 로그를 기간과 조건별로 조회하고, 트랜잭션 흐름과 메시지 상세를 확인하는 웹 애플리케이션입니다.

**[Y17 Log Workspace 접속](https://y17-ph-1.wnytech.co.kr)**

## 화면 구성

왼쪽 메뉴에서 프로그램을 선택합니다. 각 화면의 검색조건과 조회 결과는 메뉴를 전환해도 유지됩니다.

| 화면                     | 주요 기능                                                                |
| ------------------------ | ------------------------------------------------------------------------ |
| **M14N Acell LogViewer** | G/E/S 트랜잭션 검색, 단일 로그와 서비스·이벤트·글로벌 트랜잭션 상세 조회 |
| **ARC LMS**              | 트랜잭션 키·SEQ·Full Text 검색, 연관검색과 트랜잭션 전체 로그 조회       |

## 주요 기능

- **로그 검색** — 달력·직접 입력·빠른 기간 선택으로 최근 7일 내 기간을 지정하고, 시스템, 로그 종류, 트랜잭션명 등으로 조회합니다. 시간은 한국 시간(KST)으로 표시합니다.
- **트랜잭션 강조** — 두 화면 모두 같은 트랜잭션명의 행과 선택한 셀의 같은 컬럼·같은 값을 강조합니다. 색상을 직접 바꿀 수 있으며, 전체 검색결과의 강조 개수 확인과 강조된 행만 모아보기를 지원합니다.
- **결과 정리** — 컬럼별 오름차순·내림차순 정렬, 드래그로 컬럼 순서 변경, 전체 페이지 수 확인과 원하는 페이지로 바로 이동을 지원합니다.
- **메시지 상세** — 로그 원문과 XML·SQL·JSON 정렬 보기, Key = Value 상세 보기를 제공합니다.
- **여러 조회창** — 프로그램별 최대 4개 조회창을 열어 탭 또는 수평·수직 배치로 비교할 수 있습니다.
- **검색조건 관리** — 자주 사용하는 조건을 저장하고 불러오거나 초기화할 수 있습니다.
- **결과 활용** — 현재 페이지 내 검색, 행 우클릭 복사, 로그 시각을 검색 시작 시간으로 지정, 연관검색 새 창 열기를 지원합니다.

## 이용 방법

1. 왼쪽 메뉴에서 **M14N Acell LogViewer** 또는 **ARC LMS**를 선택합니다.
2. 조회 기간과 검색조건을 입력하고 **검색**을 누릅니다. **더미 로그 조회**를 누르면 데이터의 마지막 1시간을 MES 조건으로 바로 조회합니다.
3. 결과에서 로그를 선택해 메시지와 같은 트랜잭션명의 행을 확인하고, 상세 탭에서 관련 로그를 살펴봅니다.

현재 두 화면은 MES·EAP·FDC·APC의 **더미 로그 300만 건**을 공통으로 사용합니다. 실제 운영 로그는 포함되어 있지 않습니다. 상세 화면에서 불러온 로그 저장은 가능하며, 전체 기간 로그 다운로드는 아직 제공하지 않습니다.
