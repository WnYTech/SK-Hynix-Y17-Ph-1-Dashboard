# 로컬 더미 로그

사용자의 300만 건 생성·적용 요청에 따라 두 프로그램에서 공통으로 조회하는 개발 데이터 소스를 추가했습니다. 운영 데이터와 WeshBoard 코드는 사용하지 않습니다.

## 구성

| 항목     | 값                                                    |
| -------- | ----------------------------------------------------- |
| 총 행    | 3,000,000                                             |
| 시스템   | MES / EAP / FDC / APC, 각 750,000행                   |
| 트랜잭션 | 250,000개, 각 12행 / E 3개 / S 6개                    |
| 기간     | 생성 시점 약 2초 전까지 최근 6일, 고정 시각           |
| 메시지   | MES JSON, EAP XML, FDC SQL, APC Key=Value             |
| 표식     | DEMO 식별자, DUMMY 또는 dummy 메시지                  |
| 저장     | backend/data/dummy-logs.sqlite3, 약 1.56GiB, Git 제외 |

G ID와 ARC 키는 서로 다른 계약 필드로 유지하되 이 더미에서는 동일한 `DEMO-TX-0000001` 형태의 값을 넣습니다. 실제 프로그램 간 키 관계를 가정하거나 확정한 것은 아닙니다. 시스템·프로세스·클래스·소요시간·LOT/EQP·로그 종류는 모두 합성 값입니다.

## 사용

기존 서버가 실행 중이면 새로고침 후 **더미 로그 조회**를 누릅니다. MES와 데이터 마지막 1시간을 채우고 실제 API 검색을 실행합니다. 새로고침만으로 사용자의 기존 검색조건을 자동 덮어쓰거나 전체 300만 건을 전송하지 않습니다. 다른 시스템과 기간은 검색조건에서 선택합니다. 7일 전체 기간에서 각 시스템 75만 건을 확인할 수 있습니다.

한 로그를 선택하면 단일 메시지를 보고, Acell S/E/G 탭 또는 ARC 전체 로그 탭으로 연관 시스템의 로그를 조회합니다. JSON/XML/SQL 표시 형식은 선택한 메시지에 맞게 고릅니다. ARC의 연관검색 체크박스는 첫 검색에 일치한 트랜잭션들의 전체 로그를 같은 기간 내에서 반환합니다.

```bash
# 저장소 루트에서 최초 생성
npm run data:generate
# 고정 날짜가 오래되어 새로 생성할 때
npm run data:generate -- --replace
```

파일은 임시 경로에 생성·검증 후 원자적으로 교체합니다. 생성된 날짜는 자동 갱신되지 않습니다. 시간이 지나 조회 제한(최근 7일)에 걸린 행은 검색에서 제외됩니다. 데이터 전체가 만료되면 빠른 조회 버튼을 비활성화하고 재생성을 안내합니다. 재생성 후 화면을 새로고침하고 다시 검색하세요.

## 검색 규칙

- 시간 시작/끝 포함, 최신 시각 → 동일 시각 ID 내림차순.
- System을 고르면 ID 없이 검색. 전체 System은 Acell G ID / ARC 키 필수.
- 배열 필터는 정확히 일치하는 값 중 OR, 서로 다른 필터는 AND.
- OR / AND는 MSG 내 부분 문자열 검색. Full Text는 입력 문장 전체의 부분 문자열 검색. ASCII 대소문자를 구분하지 않고 `%`, `_`, 따옴표는 리터럴로 처리합니다. 오타 유사검색은 지원하지 않습니다.
- ARC 연관검색은 페이지 제한을 적용하기 전에 일치하는 모든 키를 찾습니다. 그 키의 로그를 시간 범위 내에서 시스템을 넘어 합친 뒤 페이지를 나눕니다.
- 응답은 최대 1,000행과 정확한 전체 건수, 처리시간, 다음 커서. 임의 페이지 점프는 제공하지 않습니다.
- 커서는 데이터셋과 검색조건에 묶이며 첫 응답부터 15분간 유효합니다. 최근 7일 조건의 첫 조회가 승인되면 그 기간을 페이지 이동 동안 고정하므로, 시간이 흐른 뒤 첫 페이지로 돌아와도 조회할 수 있습니다. 위변조·다른 조건 사용·15분 만료·DB 교체 시 422를 반환합니다.
- SQLite 전체 로그 내보내기 작업은 미구현입니다. 다운로드 요청은 비활성이고 API도 501을 반환합니다. 상세 탭에서 이미 불러온 로그 저장은 기존 기능을 사용합니다.

## 검증 범위

백엔드는 소규모 임시 DB로 생성 무결성·필터 조합·시간 경계·전체 페이지 중복/누락·교차 시스템 확장·커서 검증/교체·미연결 및 내보내기 미지원 상태를 검사합니다. 브라우저의 `dummy.spec.ts`는 실제 300만 건 DB에서 두 프로그램의 검색·페이지 이동·강조·상세·ARC Full Text/연관검색과 모바일 가로 넘침을 검증합니다. 실제 소스가 없는 환경에서는 해당 브라우저 테스트만 건너뜁니다.

SQLite는 개발용 데이터 확인 수단입니다. 운영 ES 매핑·권한·인증·대용량 내보내기·운영 환경의 성능 검증은 별도 작업입니다.
